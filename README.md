# Minova Main

The central home for Minova's independent software projects. The site introduces the maker behind Minova and directs visitors to every live project and source repository.

The visual system follows the official Minova Brand Kit 2.1: graphite surfaces, the cobalt-to-teal spectrum, Bahnschrift display typography, Segoe UI interface typography, and the approved Prism M artwork.

## Development

```powershell
npm install
npm run dev
```

## Production check

```powershell
npm run build
npm test
```
